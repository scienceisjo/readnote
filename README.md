# 읽기 노트

학생이 책을 읽으며 질문과 내 말 요약을 남기고, 선생님이 그 기록을 모아 보는 웹앱입니다.

- 학생: `index.html` — 참여코드 + 학번 + 이름으로 들어와요
- 선생님: `teacher.html` — 읽기 방을 만들고, 진행·질문·막힌 곳을 봐요
- 설치: `setup.sql` — Supabase SQL Editor 에서 한 번 실행

## 학생이 하는 일

1. **읽기 전** — 이 책에서 알고 싶은 것을 질문 하나로 적어요. (핵심 개념이 있으면 그 개념에 대한 지금 생각 한 줄)
2. **읽는 동안, 부분마다** — 내 말로 한두 줄 요약 + 읽으며 생긴 질문. 앞에서 쓴 요약이 다음 부분 위에 이어서 보여요. 질문이 막히면 말머리(뜻·정말?·견주기·왜·만약·우리 곁에서·눈에 띈 것)를 눌러 시작해요. 마음에 남은 구절은 옮겨 치고, 막힌 곳은 표시해요.
3. **읽은 뒤** — 처음 질문에 내 답, 이 책을 한 문장으로, 새로 생긴 질문.
4. **AI는 나중에** — 요약을 20자 이상 쓴 뒤에야 「AI에게 내 이해 확인받기」가 열려요. 부탁문은 답이 아니라 질문을 달라고 하고, 「정리만 맡기기」는 내 말을 그대로 두고 묶기만 해 달라고 해요. 서버가 AI를 부르지 않고, 학생이 학교에서 쓰는 AI에 붙여 넣어요. 부탁문에 이름·학교는 들어가지 않아요.

## 선생님이 보는 것

- 진행 상황: 학생 × 부분 표(다 씀 / 쓰는 중 / 아직), 줄을 누르면 그 학생 기록 전체
- 모아 보기: 부분별 학생 질문 / 내 말 요약(같은 부분을 반 아이들이 어떻게 요약했나) / 핵심 개념 생각 변화(처음 → 읽은 뒤)
- 막힌 곳 · 남은 구절: 어디서 많이 막혔는지 막대로
- 칠판에 띄우기: 학번·이름을 가리고 순서도 섞고 글씨를 키워요
- 반 고르기: 학번이 5자리(학년·반·번호)면 한 방을 여러 반이 써도 반별로 거를 수 있어요
- 엑셀로 내려받기(CSV): 학생·부분마다 한 줄
- 방 설정: 부분 더하기·이름 고치기(기록 있는 부분은 못 지움), AI 칸 끄기, 마감(학생은 볼 수만 있음), 학번 잘못 친 학생 고치기·지우기

## 왜 이렇게 만들었나

| 장치 | 근거 |
|---|---|
| 읽기 전 질문 하나, 부분마다 질문 | 질문을 만들며 읽으면 이해·기억이 오른다(Rosenshine·Meister·Chapman 1996 메타분석), EBS 「다시, 읽기로」 2부의 질문하며 읽기 실험 |
| 부분마다 스스로 요약, 앞 요약이 다음 부분의 길잡이 | 나민애 교수(EBS 「나의 두 번째 교과서」 국어 1강) 챕터별 요약 읽기, 2022 개정 국어 [9국02-02] 요약·[9국02-08] 읽기 과정 점검 |
| 구절은 옮겨 치기 | 같은 특강의 「타이핑하면 깊이 들어온다」, 생성 효과 |
| AI는 스스로 쓴 뒤에만, 답 대신 질문 | 먼저 스스로 애쓴 뒤 AI를 쓰자는 제안(Kosmyna 외 2025), 답 대신 힌트를 준 AI는 학습 손해가 적었다(Bastani 외, PNAS 2025) |
| 막힌 곳 표시 | 읽기 과정 점검·조정, 선생님이 다음 시간에 짚을 곳 |

## 처음 설치 (한 번만)

1. Supabase 프로젝트 → SQL Editor → `setup.sql` 통째로 붙여 넣기 → Run
2. 마지막 결과에 `rn_` 함수 9개가 보이면 끝
3. 다른 Supabase 를 쓰려면 `rn.js` 맨 위 `CFG.url`·`CFG.key`(공개 키)만 바꿔요

표(rn_rooms·rn_readers·rn_entries)는 공개 키로 직접 읽고 쓸 수 없고, 함수로만 드나들어요. 선생님 비밀번호(6자 이상)는 암호화해서 저장하고, 10번 틀리면 그 방은 10분 동안 잠겨요. 비밀번호는 「기억하기」를 켰을 때만 그 기기에 남아요.

알아 둘 점: 학생은 비밀번호 없이 학번+이름으로 들어와요(외울 것을 만들지 않으려고). 그래서 친구 학번과 이름을 아는 학생은 그 친구 노트에 들어갈 수 있어요. 공용 기기에서는 3시간이 지나면 「○○ 학생으로 이어서 쓸까요?」를 묻고, 학생 화면 위에 학번·이름을 크게 보여 줘요.

## 내년 전에 키울 것

- 우리 반 질문 벽(학생끼리 이름 없이 질문 보기·답 달기) — 함께 읽기
- 선생님 한마디(기록에 되묻기 달기)
- 여러 권을 한 학기로 묶기, 학생별 독서 이력
- 질문 바구니(찾아보면 아는 것·해 봐야 아는 것 …)로 질문 나누기
- 인쇄용 독서 기록장 다듬기
- 학생 기록 이전 판 남기기(잘못 지운 글 되살리기), 반 명단을 넣어 아직 안 들어온 학생 보기
- 두 기기에서 같은 칸을 고칠 때 충돌 알리기(지금은 나중에 저장한 글이 남음)
